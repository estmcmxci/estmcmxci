I work across software, writing, and media. I build products that reveal the structures hidden within systems and render them into usable form.

I believe this work sits upstream of capital formation, and I place bets based on the insights it produces.

Selected code, research and contributions below.

### DNSSEC verification

Contributed the P-256 precompile integration merged into ENS’s contracts. Built a measurement harness to compare verification costs using deployed bytecode and historical DNS-import proofs.

[Merged contribution](https://github.com/ensdomains/ens-contracts/pull/509) · [Measurement harness and data](https://github.com/estmcmxci/algo13-study)

### Cross-venue market research

Executed an IPO basis trade pairing brokered equity with short perpetual futures. Built a public-data harness to examine funding, liquidity and price behavior across pre-IPO perpetual markets, distinguishing reproducible measurements from private trade records.

[Research harness](https://github.com/estmcmxci/spcx-harness) · [Trade write-up](https://estmcmxci.co/writing/spcx/)

### ENSv2 developer tooling

Built a CLI plugin for registering names, configuring resolvers and linking agent identities through MetaMask Agent Wallet. Provisioning resumes after interruption and checks onchain state before repeating a transaction. Sepolia only.

[Code and installation](https://github.com/estmcmxci/mm-plugin-ensv2) · [Documentation](https://mm-ensv2.estmcmxci.co)

### TLD assignment

Built a Sepolia prototype for registry operators to prove DNS control and request TLD assignment under standing rules, with a timelock and governance veto. Current work examines assignment and subsequent control in ENSv2; production integration remains unresolved.

[Prototype and demonstrations](https://github.com/steg-eth/dnssec-solutions) · [ENSv2 design and limitations](https://github.com/steg-eth/tld-oracle-v2)

### Agent operations

Built Oikonomos, an application for deploying agent wallets, registering identities and ENS names, and managing fee collection through delegated permissions and scheduled execution. Demonstrated on Base Sepolia and Ethereum Sepolia.

**ETHGlobal HackMoney 2026 finalist.**
